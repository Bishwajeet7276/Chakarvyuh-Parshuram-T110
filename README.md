# ⚡ Smart ENTC Learning & Innovation Platform

An interactive, student-friendly web platform designed to support Electronics and Telecommunication Engineering (ENTC) students through digital learning, technical resources, and innovation-focused activities.

## 🚀 About the Project

The **Smart ENTC Learning & Innovation Platform** aims to bring learning resources, engineering concepts, and innovation opportunities together in one accessible place.

The platform is designed to help students explore technical topics, strengthen their understanding, and discover opportunities to learn beyond the classroom.

## ✨ Key Features

- 📚 **Learning Resources:** A dedicated space for ENTC-related educational content.
- 💡 **Innovation & Projects:** Encourages students to explore ideas and technical projects.
- 🎓 **Student-Friendly Interface:** Simple navigation and an accessible learning experience.
- 📱 **Responsive Design:** Designed to work across desktop, tablet, and mobile screens.
- 🌐 **Web-Based Platform:** Accessible through a web browser.
- 🧩 **Expandable Architecture:** Can be extended with additional learning tools and features.

> Features listed above should reflect the functionality currently implemented in the project. Update this section if any feature is planned but not yet available.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### Prerequisites

Install the following:

- [Node.js](https://nodejs.org/)
- npm, included with Node.js
- Git

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd smart-entc-learning-platform
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

### Build for Production

To create a production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
